A program that writes one funny passive-aggressive note a smart fridge leaves for its owner — a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen. Pure Python standard library, no dependencies.

## Run it

```sh
python3 main.py
```

It writes the note to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
